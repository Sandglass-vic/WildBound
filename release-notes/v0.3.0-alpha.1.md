第一个 Godot 版本的 Alpha 试玩包（之前的 Demo v0.2 是 three.js 网页版），首次提供 macOS 和 Windows 单机构建。

构建号 18（macOS 版本 0.3.0 / 18，Windows 文件版本 0.3.0.18）。

## 下载

| 文件 | 平台 |
| --- | --- |
| `Wildbound-0.3.0-alpha.1-macos.zip` | macOS 12+，Apple Silicon / Intel 通用 |
| `Wildbound-0.3.0-alpha.1-windows-x64.zip` | Windows 10 / 11 x64，需 Vulkan 或 D3D12 显卡 |

未签名构建：macOS 第一次请右键 → 打开（或 `xattr -cr Wildbound.app`）；Windows SmartScreen 点「更多信息 → 仍要运行」。

## 新增

- **海岛世界**：加勒比海岛、渔村与栈桥、村北的森林盆地；FFT 海面、碎浪与浪花、沙滩冲浪泡沫、水下焦散与水下画面；
  大气、体积云、昼夜与时间表盘；植被三级 LOD、林下草和蕨类；环境音（海浪、鸟鸣、蟋蟀、鲸声）。
- **局内 / 局外**：出生房（C 栋）是家，穿过房门出门、回家，带过门动画；出门和回家都会存档。
- **金币**：只在家里能用，左上角常显。
- **人物**：幸存者模型带背包，第一人称手臂与身体阴影，O 切换第三人称；步行、冲刺、游泳、爬梯子。
- **背包 · 仓库 · 装备**：格子拖拽（参考我的世界），人物旋转预览，双击使用；手上装备 1–4 快捷栏。
- **商店**：家里的木牌前按 F 买卖物品。
- **制造**：制作台配方，用采集到的材料做出消耗品和工具。
- **采集**：贝壳、海葡萄、椰子、香蕉，F 采集，会重新长出。
- **生存系统**：体力、血量、水分、饱食度、气息、中毒 / 流血、睡眠；野外死亡会失去背包和随身装备，仓库与金币保留。
- **帐篷**：B 键选址扎帐篷，进帐篷选择起床时间睡觉。
- **随从**：出门前选一个随从获得能力（矛头蝮夜视、角雕高跳、美洲黑熊加血量上限），G 发动。
- **蛇**：矛头蝮 AI（漫游、警觉、蓄力出击、咬住、逃跑），咬中会中毒，E 甩开；夜里林地会出现林蛇。
- **手上工具**：小刀刺、蛇钩压蛇与提起、麻醉枪（开镜、装弹、麻醉针累计致晕）、手电筒。
- **物品**：53 件物品，均有模型和背包图标。

## 变更

- **启动游戏总是在家里**：不管上次存档是出门还是回家，打开游戏都在屋里、早上 8:00；中途退出的那一局作废，
  背包保留出门时存档的内容，那一局扎下的帐篷丢失。
- **装备可以放进背包**：背包的 20 格什么都能放，装备每格 1 件；背包格里的装备只是带着，只有手上装备 1–4 里的
  能拿在手上，帐篷要在帐篷格才能扎。Shift + 点击：仓库里的装备先穿到空着的对应部位、没有就放进背包；
  没开仓库时，背包里的装备穿到对应部位，身上的装备脱回背包。局内捡起装备时对应装备格满了就放进背包。

## 修复

- **夜视在深夜也看得清**：矛头蝮「热感」现在会放大场景本身的光（环境光加强、曝光一路补到能看清），
  不用手电筒也能看清林下和沙滩，0.3 秒淡入淡出。

## 存档

- 存档格式版本 1（`save.json` 的 `version`）；初始物品补发版本 2（`kit`），老存档会在仓库里收到一次新加入的初始物品。

## 已知问题

- 动物园和捕捉还没有实现，三个随从目前都可以直接选择。
- 这是 Alpha 构建：之后的版本可能重置存档。
