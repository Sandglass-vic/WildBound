0.3.0-alpha.1 的又一个试玩构建：应用图标、启动加载界面，以及针对 Windows 启动崩溃的修复。

构建号 19（macOS 版本 0.3.0 / 19，Windows 文件版本 0.3.0.19）。

## 下载

| 文件 | 平台 |
| --- | --- |
| `Wildbound-0.3.0-alpha.2-macos.zip` | macOS 12+，Apple Silicon / Intel 通用 |
| `Wildbound-0.3.0-alpha.2-windows-x64.zip` | Windows 10 / 11 x64，需 Vulkan 或 D3D12 显卡 |

未签名构建：macOS 第一次请右键 → 打开（或 `xattr -cr Wildbound.app`）；Windows SmartScreen 点「更多信息 → 仍要运行」。

## 新增

- **应用图标**：macOS 和 Windows 版都换成了游戏里的海边截图（沙滩、浪花和栈桥），窗口和任务栏图标也一样。
- **启动加载界面**：打开游戏时先显示渔村海边的画面、标题和进度条，逐项显示正在加载的内容（地形、海洋、
  植被……），加载完淡出进入游戏，不再是一个卡住不动的窗口。

## 修复

- **Windows 版启动时内存分配失败（`Parameter "mem" is null`，`memory.cpp:104`）**：植被同一网格的几组树冠
  合成一批，渲染批次少了约四分之一，画面不变。日志改为每行立即写入，加载的每一步都记下耗时、显存和系统可用内存。
  如果仍然打不开，请把 `%APPDATA%\Godot\app_userdata\Wildbound\logs\godot.log` 连同显卡型号和内存大小发到
  [Issues](https://github.com/Sandglass-vic/WildBound/issues)。

## 存档

- 存档格式不变（版本 1），0.3.0-alpha.1 的存档可以直接继续用。

## 已知问题

- 新版本第一次打开要编译着色器，加载界面会在「采集物与蛇」一步停十几秒，之后再打开只要几秒。
- 动物园和捕捉还没有实现，三个随从目前都可以直接选择。
- 这是 Alpha 构建：之后的版本可能重置存档。
